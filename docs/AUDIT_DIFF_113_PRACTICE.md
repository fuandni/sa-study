# 2026-10-15 データ差分113問の確認演習

## 目的

GitHubに保存されていた**旧配布用JavaScript**と、同じ時点の**原本JSON**の間に、全フィールド比較で差があった問題だけを再演習するための固定スナップショット。

**重要：113問の正解が誤っていたという意味ではない。** OCR問題文が更新された差分だけでなく、図表の再生成・注記など表示用メタデータだけの差分も含む。OCIデプロイ時にはもともと原本JSONから配布用JSを再生成していたため、この113問を「本番で古い問題が表示されていた113問」と断定しない。

## 対象を確定した方法

- 比較元コミット（PR #22での同期修正前）：[`3696e40462e2d8265f646cd5e60639c6a8aa73b3`](https://github.com/fuandni/sa-study/commit/3696e40462e2d8265f646cd5e60639c6a8aa73b3)
- 同一コミットの `a1/data/a1_questions.json` と `data/a1_questions.js` を位置・ID順に比較：**49問**
- 同一コミットの `am2/data/am2_questions.json` と `data/am2_questions.js` を位置・ID順に比較：**64問**
- 全フィールド `JSON.stringify()` で差があるレコードの **問題IDを113件** 記録。重複なし。
- 固定ID一覧：[`data/audit_diff_113.js`](../data/audit_diff_113.js)。**今後問題本文が修正されても対象集合は自動変更しない**。

| 科目 | 件数 | 主な要因 |
|---|---:|---|
| 午前Ⅰ | 49問 | 2017年30問の本文構造化、個別設問の文面、図表復元メタデータなど |
| 午前Ⅱ | 64問 | 2015〜2017年のOCR本文と選択肢の構造化、図表復元メタデータなど |
| **合計** | **113問** | |

## 使い方

1. 学習サイトの上部「**差分113問**」またはホーム画面「**差分113問の専用メニューを開く**」を選択。
2. 「113問すべて（年度・問番号順）」で通し演習する。必要なら「午前Ⅰのみ49問」「午前Ⅱのみ64問」「ランダム10問」を使用。
3. 「未回答」「誤答経験あり」「★ 要復習」では **この113問の中だけ** を、通常の保存済み回答履歴から抽出する。
4. 途中終了・途中再開、結果表示、復習、履歴記録は通常演習と共通。113問専用の履歴形式や別保存場所は作らない。

## 品質維持

- 存在しない問題ID、重複ID、49＋64問の内訳が変わった場合はメニューの演習開始ボタンを無効にする。
- `tests/test_audit_113_menu.cjs` で対象113問、種別7通り、履歴・途中再開・通常の要復習を確認。
- 550問の原本JSON/JS完全同期テストとは目的を分ける。
- 通常の550問メニュー、問題ID、正答、既存の履歴は変更しない。
