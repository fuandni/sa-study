# SA 午前II 2015–2017 テキスト化：校正状況

## 対象
- 2015年度 問1〜25：25問
- 2016年度 問1〜25：25問
- 2017年度 問16〜25：10問
- 計60問（問題本文＋ア・イ・ウ・エの選択肢240件）

## 変更点
`am2/data/am2_questions.json` の対象60問に限り、`question_text` と `choices` を画像参照用プレースホルダから読取テキストに更新。
既存の `id`、`year`、`question_no`、`answer`、`asset_path`、`asset_type`、`source_file`、`source_page` は維持。
原本ページ画像は、図表および未了校正への対照資料として当面継続表示。

## 確認
- 対象60件、固有ID60件、問題年度・番号・正答に不一致なし。
- 選択肢が全問4件そろっており、空欄・プレースホルダ選択肢なし。
- テキストを2015・2016・2017年度の既存OCR読取テキストと機械的に照合し、画像・表・OCR誤読に起因する低一致候補を抽出。
- 数式、表、図に依存する設問（例：2015問5・10・12、2016問3・11・24、2017問20・21・22）は原本ページ画像を目視して重点点検。
- ただし、全60件の完全な逐語・図表再現校正が済んだことは意味しない。

## 残作業
- 全60問を原本PDFと逐語校正。
- 図表依存設問は、必要に応じて問題単位の画像へ切出し、元ページ全体表示を解消。
- アプリの演習画面で、本文・選択肢・原本画像が正しく表示されることを確認。
- 最終確認後にのみ、このPRをmainへマージ（mainへのpushでOCIへ自動デプロイ）。

## データ品質表示

「公式PDFとの逐語確認済み」などの確定扱いはしない。
