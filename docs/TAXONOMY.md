# 学習用分類 v1（2026-10-15）

## 目的
- 元データ（a1/data/a1_questions.json、am2/data/am2_questions.json）の category / subdomain は**変更しない**。
- 表示・集計用に assets/js/taxonomy.js が category / subdomain を統一する。original_category / original_subdomain に元値を保持。
- 問題ID、出題内容、正解、回答履歴（localStorage・OCI同期）は変更しない。

## 分類の仕組み
- 大分類は10、細分類は31。
- 元分類がある400問は、元の subdomain 名の完全一致で変換（status: 正規化）。
- 元分類がない午前IIの60問（2015年25、2016年25、2017年10）は、OCRで読める問題文に基づく**暫定分類**（status: 暫定（OCR本文））。視覚監査完了の意味ではない。
- 元分類がない午前Iの90問（2015〜2017年度）は、共通午前Ⅰの外部論点・分野索引（各年度30問）から**暫定分類**（status: 暫定（外部論点索引））。公式問題本文・選択肢の全件目視監査ではないため、証拠レベルを分ける。
  - [2015年度（平成27年秋期）](https://www.nw-siken.com/kakomon/27_aki/)
  - [2016年度（平成28年秋期）](https://www.nw-siken.com/kakomon/28_aki/)
  - [2017年度（平成29年秋期）](https://www.nw-siken.com/kakomon/29_aki/)
- これで統計用の分類空欄は **0問**。ただしOCR本文60問＋外部分類索引90問の計150問は暫定扱い。
- 2015〜2017年度午前Ⅰ90問について、外部索引の論点から短い見出しを付与。問題文の差替えではない。元の `question_text` と `topic` は保持し、表示時だけ `topic` を補完し `original_topic` に元の値を残す。全90問は `topic_status: 外部論点の短い要約` を持つ。
- 演習画面・復習画面に論点要約と根拠サイトへのリンクを表示。これは元問題本文・正答・問題画像の検証完了を意味しない。
- 未知の subdomain が追加された場合は意図的に未分類になる。暗黙のカテゴリ継承や字面の部分一致はしない。

## 集計
- 初回正答率：問題IDごとの時刻順最初の回答。再回答の結果は含めない。
- 最新正答率：問題IDごとの時刻順最後の回答。
- 改善：初回不正解、最新正解になった問題ID数。
- 累積正答率：従来どおり全回答（再回答を含む）。分類別能力を比較するときは初回を優先。
- 5問未満の分類には「参考値」を付ける。標本数が少ない結果を強い傾向と見なさない。
- 学習優先度：2019・2021〜2025年の6回の同一統一細分類の実問題数／6 × 初回誤答率の平滑推定。未分類はランキングから除外する。
- 従来の、該当する細分類頻度がないと大分類の頻度（例18問/回）を代用する処理は廃止。

## 原本照合の範囲（2026-10-15）
IPA公式の2015・2016・2017年度午前Ⅰの問題冊子PDFを確認し、**各年度の3ページにある冒頭の問題**と外部論点一覧の対応を目視スポットチェックした。
- 2015: 集合の包含関係、パリティ、ハッシュ表
- 2016: 数値計算の二分法、有限オートマトン
- 2017: 相関係数、可変長符号化、階乗を計算する再帰関数

**全90問の図表・問題本文を確認したわけではない**。この段階で外部分類のステータスを「正規化」に格上げしない。

## 公式PDFの設問主題照合（2026-10-15 完了）
外部分類索引で暫定分類した2015〜2017年度午前Ⅰ90問について、IPA公式問題冊子PDFのページ画像で、**問題番号・論点要約・大分類の整合を全90問確認**した。

- 2015年度：問1〜30（30問）
- 2016年度：問1〜30（30問）
- 2017年度：問1〜30（30問）
- **午前Ⅰの主題照合は90/90問**。午前ⅡのOCR本文由来60問は今回の監査対象外で、引き続き要確認。

前回残っていた22問は、原本PDFの未確認10ページを専用監査ブランチで画像化し、直接読んで照合した。画像が一時的に必要なだけなので、製品配布用の問題アセットは増やしていない。

「公式PDFで設問主題を照合済み」の追加表示用メタデータ `topic_review_status` と原本PDFの該当ページリンク `topic_review_source_url` は90問すべてにある。一方、外部論点索引から付与した `classification_status` は暫定扱いのまま維持する。

**重要**：これは「設問の論点が合っている」の照合であり、選択肢・正答・図表細部・全文字起こしを含む完全な問題品質監査ではない。問題ID、問題本文、正解、回答履歴は変更していない。

## 公式PDF OCR下書き（2026-10-15）
公式問題PDFを原本SHA-256で識別し、2015年13頁・2016年14頁・2017年12頁、合計39頁について、ページ単位の日本語OCR下書きを `source_ocr/{year}_a1_unreviewed.txt` と `source_ocr/legacy_a1_ocr_index.csv` に保存。

- OCRは未校正。例えば2016年度問30を「問39」と誤読した。
- OCRから問題本文・図表・選択肢・正解を自動上書きしない。
- 主題照合が全件完了しても、原文テキストの構造化状況とは別の品質指標である。
